The model is a logistic regression over 31 numeric features describing a street segment: its highway class, footway kind, length, nearby counts of bus stops, food places, shops and buildings, and land use. Counts are scaled within each city. Each feature gets a weight; the weighted sum is turned into a number between 0 and 1 that estimates how likely a street like this is to be tagged lit in OpenStreetMap. Weights are learned from streets that people have already tagged. Untagged streets count only a little as examples of 'not lit', because untagged means unknown.
